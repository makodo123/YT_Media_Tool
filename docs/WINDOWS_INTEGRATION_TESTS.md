# Windows 實機整合測試清單

以下項目需在 **Windows 11 x64 實機**（建議另備一台乾淨、未安裝 Python / FFmpeg 的 VM）上執行。
自動化 pytest 不連線 YouTube，因此下列項目必須人工驗證後才能發行。

測試素材請使用您擁有權利或明確允許下載的影片（例如自己頻道上傳的公開 / 不公開影片、Creative Commons 授權影片）。

記錄格式：`項目編號 / 結果（通過 / 失敗）/ 備註 / 測試者 / 日期 / 版本`

## A. 建置

| # | 步驟 | 預期結果 |
|---|---|---|
| A1 | 乾淨環境執行 `scripts\setup_windows.bat` | 建立 `.venv`，所有套件以 wheel 安裝成功 |
| A2 | `set QT_QPA_PLATFORM=offscreen` 後執行 `python -m pytest` | 全部通過（含 integration；FFmpeg 已在 vendor 或 PATH） |
| A3 | `packaging\ffmpeg_manifest.json` 填入經官方比對的 SHA256 後執行 `scripts\build_exe.bat` | 5 個步驟全部完成，產生 `dist\YT_Media_Tool\YT_Media_Tool.exe`、`_internal`、zip、`.sha256` |
| A4 | 竄改 `vendor\downloads` 中的 FFmpeg zip 後以 `-Force` 重跑 `fetch_ffmpeg.ps1` | 顯示 SHA256 不符並中止 |
| A5 | `scripts\build_exe.bat --no-ffmpeg` | 建置成功，`_internal` 中沒有 ffmpeg 資料夾 |
| A6 | 檢查 EXE 內容 → 詳細資料 | 顯示產品名稱 YT Media Tool、版本 2.0.0、圖示正確 |
